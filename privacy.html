Privacy Policy

Last updated: 2026-11-09

Tony Channel Stats is a personal tool used only by its owner, for YouTube channels the owner runs. It is not offered to anyone else.

What it accesses

With the owner's permission, it uses read-only access to the YouTube Data API and the YouTube Analytics API. It reads channel details, video lists and performance statistics such as views, watch time and subscribers gained. It cannot upload, edit or delete anything.

How the data is used

The statistics are used only to help the owner track and plan their own channels.

Where the data is kept

Sign-in tokens are stored only on the owner's own computers. Statistics are kept in the owner's private notes and private code repositories, and are processed by the owner's AI assistant (Claude, by Anthropic) when the owner asks for analysis.

Sharing

The data is not sold, not used for advertising and not shared with anyone beyond the services named above.

Removing access

Access can be withdrawn at any time from the Google account permissions page.

YouTube and Google terms

This tool uses YouTube API Services. See the YouTube Terms of Service and the Google Privacy Policy.

Contact

Questions can be raised as an issue on this project's page.
